Keyboard and mouse from your PC on the Steam Deck, Game Mode included: two files, run the installer and it sets everything up

## Download

- **PC (Windows)** — `SteamDeck-KVM-1.0.0-windows-x64-setup.exe`: run it; it installs, adds shortcuts and starts the app.
- **Steam Deck** — `SteamDeck-KVM-Install.desktop`: download in Desktop Mode and double-click. The app is inside the file, so it installs without further downloads.

"Source code" archives are added by GitHub to every release and are not needed to install.

## What you get

- **Game Mode works** — the cursor moves in Game Mode and on the desktop; stuck Win/Shift/Ctrl no longer break keys in games.
- **Instant switch** — push the cursor past the screen edge or press `Ctrl+Alt+→` / `Ctrl+Alt+←` (any keyboard layout).
- **No lost input** — when the Deck screen is off or the Deck sleeps, the cursor stays on the PC.
- **Apps on both devices** — connection status, the paired PC or Deck, forget, update, uninstall.
- **Update button** on both devices runs the installer of the latest release; pairing and settings are kept.
- **Your languages on the Deck** — keys arrive as physical keys, the Deck gets the PC's keyboard layouts, `Alt+Shift` switches them (Game Mode picks them up after a restart).
- **Smooth over Wi-Fi** — the installer turns off Wi-Fi power saving for the current network, which caused lag spikes of up to ~0.4 s.

## Known issues

- The Windows installer is not code-signed: SmartScreen may show "Windows protected your PC" — click **More info → Run anyway**.
- Installed a test build from the repository before this release? Run the installer once; pairing is moved over.
- No clipboard sharing and no file drag-and-drop; the connection is unencrypted — use it on a trusted home network.

## По-русски

- **Игровой режим работает**, переход на Deck мгновенный, курсор не уходит в уснувший Deck.
- **Два файла на выпуск:** установщик для компьютера и ярлык установки для Steam Deck — скачали, запустили, всё настроилось само.
- **Кнопка «Обновить»** на обоих устройствах запускает установщик последнего выпуска; знакомство и настройки сохраняются.
- **Русский на Deck'е** — клавиши приходят физическими, раскладки те же, что на компьютере, переключение `Alt+Shift`.
- **Без рывков по Wi-Fi** — установщик выключает экономию питания Wi-Fi для текущей сети.
- Ставили пробную сборку из репозитория — один раз запустите установщик: знакомство перенесётся.
- У установщика для Windows нет платной цифровой подписи: нажмите «Подробнее → Выполнить в любом случае».
