Mouse and keyboard now work in Steam Deck Game Mode, one-click install on the Deck, in-app updates

## Download

- **Steam Deck** — `SteamDeck-KVM-Install.desktop`: download in Desktop Mode and double-click; it fetches and installs the rest.
- **Steam Deck, offline** — `SteamDeck-KVM-1.0.0-steamos-x86_64.tar.gz`: extract and run `bash install.sh`.
- **PC (Windows)** — `SteamDeck-KVM-1.0.0-windows-x64.zip`: unzip anywhere and run `SteamDeck-KVM.vbs`.
- **Checksums** — `SHA256SUMS.txt`; the installer and both apps verify downloads against it.

## Breaking changes

- Hotkeys moved to `Ctrl+Alt+→` / `Ctrl+Alt+←`: the old letter hotkeys did not work with non-Latin keyboard layouts.
- The Deck part now runs as a user service. Run the new installer once over the old version — it moves your pairing over and asks for the Deck password only to switch off the old system service.

## Added

- **Steam Deck app** — shows the connection and the paired PC; forget the PC, update or uninstall from the window.
- **One-click install and updates** — no terminal, no git. An **Update** button appears in both apps when a new release is out; pairing and settings survive updates.

## Fixed

- **Game Mode** — the cursor moves with relative motion in Game Mode (gamescope ignores absolute pointer axes) and with the absolute axis on the desktop, switching on the fly.
- **Stuck modifiers** — Win/Shift/Ctrl are re-synced with the PC on every key press, so a lost key-up can no longer turn every key in a game into a shortcut.
- **Slow switch** — no delay at the screen edge.
- **Lost input** — when the Deck's screen turns off or the Deck falls asleep, the cursor stays on the PC.

## Known issues

- No clipboard sharing and no file drag-and-drop.
- The connection is unencrypted: use it on a trusted home network.

## По-русски

- **Steam Deck** — скачайте `SteamDeck-KVM-Install.desktop` в режиме рабочего стола и нажмите на него: он сам скачает и установит программу.
- **Компьютер** — `SteamDeck-KVM-1.0.0-windows-x64.zip`: распакуйте и запустите `SteamDeck-KVM.vbs`.
- **Игровой режим работает** — и мышь, и клавиатура; зависшие Win/Shift/Ctrl больше не ломают клавиатуру в играх.
- **Переход на Deck мгновенный**, горячие клавиши — `Ctrl+Alt+→` и `Ctrl+Alt+←`, при любой раскладке.
- **Курсор не уходит в погасший или уснувший Deck.**
- **Окно на Steam Deck и кнопка «Обновить»** в обоих приложениях; знакомство и настройки обновление не трогает.

Старая версия уже стоит на Deck? Запустите новый установщик один раз — он перенесёт знакомство и спросит пароль только чтобы отключить прежнюю службу.
