One installer for Windows: download, run, done — shortcuts, start and updates included

## Download — two files

- **PC (Windows)** — `SteamDeck-KVM-1.1.0-windows-x64-setup.exe`: run it; it installs, adds shortcuts and starts the app.
- **Steam Deck** — `SteamDeck-KVM-Install.desktop`: download in Desktop Mode and double-click; it installs everything else by itself.

The other files are fetched automatically by the installers and the Update button: `install.sh`, the Steam Deck package `…-steamos-x86_64.tar.gz` (also works offline: extract and run `bash install.sh`) and `SHA256SUMS.txt` for checking downloads. "Source code" archives are added by GitHub to every release.

## Breaking changes

- The Windows zip is replaced by an installer. If you unzipped 1.0.0, run the new installer once and delete the old folder; pairing and settings are kept.

## Added

- **Windows installer** — installs for your user without admin rights, adds Start menu and desktop shortcuts, starts the app, appears in Windows "Installed apps".
- **Uninstall from Windows settings** — asks whether to keep the pairing with the Steam Deck.

## Changed

- **Update button on the PC** downloads the new installer, checks its checksum and runs it silently; the connection to the Deck stays up.

## Known issues

- The installer is not code-signed: Windows SmartScreen may show "Windows protected your PC" — click **More info → Run anyway**.
- No clipboard sharing and no file drag-and-drop; the connection is unencrypted — use it on a trusted home network.

## По-русски

- **Компьютер** — скачайте `SteamDeck-KVM-1.1.0-windows-x64-setup.exe` и запустите: программа установится, создаст ярлыки и запустится.
- **Steam Deck** — скачайте `SteamDeck-KVM-Install.desktop` в режиме рабочего стола и нажмите на него дважды.
- **Обновление на ПК** — кнопка «Обновить» сама скачивает и тихо запускает новый установщик.
- **Удаление** — через «Приложения» Windows; спросит, сохранить ли знакомство со Steam Deck.
- У установщика нет платной цифровой подписи: Windows может предупредить — нажмите «Подробнее → Выполнить в любом случае».
- Ставили версию 1.0.0 из zip? Запустите новый установщик один раз и удалите старую папку — знакомство и настройки сохранятся.
