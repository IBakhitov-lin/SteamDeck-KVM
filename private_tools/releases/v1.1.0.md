The cursor moves in Game Mode after an upgrade, your own languages work on the Deck, and no more lag over Wi-Fi

## Download

- **PC (Windows)** — `SteamDeck-KVM-1.1.0-windows-x64-setup.exe`: run it; it updates the app in place and starts it.
- **Steam Deck** — `SteamDeck-KVM-Install.desktop`, or press **Update** in the SteamDeck-KVM window on the Deck.

Update both devices: the Deck learns the PC's keyboard languages from the PC app 1.1.0.

## Added

- **Your languages on the Deck** — keys now arrive as physical keys and the Deck's own layout prints the letters. The Deck gets the same layouts as the PC (Latin first) and `Alt+Shift` switches them, on the desktop right away and in Game Mode after Game Mode restarts.
- **Smooth over Wi-Fi** — the installer turns off Wi-Fi power saving for the current network; it caused PC→Deck lag spikes of up to ~0.4 s.

## Fixed

- **No cursor in Game Mode after upgrading from a pre-1.0 install** — the old `/etc/deck-kvm.conf` forced the absolute pointer, which Game Mode ignores. Old settings files are no longer read at all.
- **Cursor didn't reach the right third of the Deck screen in Game Mode** — the sideways internal panel was reported as 800×1280 instead of 1280×800.

## Known issues

- Steam may still show its on-screen keyboard when a text field gets focus in Game Mode.
- The Windows installer is not code-signed: SmartScreen may show "Windows protected your PC" — click **More info → Run anyway**.
- No clipboard sharing and no file drag-and-drop; the connection is unencrypted — use it on a trusted home network.

## По-русски

- **Курсор в игровом режиме после обновления со старой установки** — старый файл настроек больше не читается.
- **Русский на Deck'е** — клавиши приходят физическими, раскладки те же, что на компьютере, латиница первой, переключение `Alt+Shift`; в игровом режиме — после его перезапуска.
- **Без рывков по Wi-Fi** — установщик выключает экономию питания Wi-Fi для текущей сети.
- **Курсор доходит до правого края** экрана Deck'а в игровом режиме.
- Обновите оба устройства: языки клавиатуры Deck узнаёт от приложения на компьютере 1.1.0.
