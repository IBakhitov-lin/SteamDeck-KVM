# SteamDeck-KVM — одна клавиатура и мышь для компьютера и Steam Deck

[English](README.md) · **Русский**

Доведите мышь до края монитора — курсор перейдёт на экран Steam Deck, клавиатура следом. Работает **в игровом режиме и внутри игр**, а не только на рабочем столе.

**[⬇ Скачать последний выпуск](https://github.com/IBakhitov-lin/SteamDeck-KVM/releases/latest)**

## Установка

### Steam Deck

1. Перейдите в **режим рабочего стола** (кнопка Steam → Питание → Переключиться на рабочий стол).
2. Откройте терминал (правой кнопкой по рабочему столу → **Открыть терминал**, либо запустите **Konsole**) и выполните:
   ```sh
   curl -fsSL https://github.com/IBakhitov-lin/SteamDeck-KVM/releases/latest/download/SteamDeck-KVM-Install.desktop -o kvm-install.desktop && python3 -c "$(sed -n 's/^Exec=python3 -c "\(.*\)" %k$/\1/p' kvm-install.desktop)" kvm-install.desktop
   ```
   Команда сама скачивает установщик под постоянным именем и сразу его запускает — браузер тут не участвует, переименовывать нечего. Пароль Deck'а спросят, только если стояла версия старше 1.0.

   Больше нравится нажимать мышью? Скачайте **[SteamDeck-KVM-Install.desktop](https://github.com/IBakhitov-lin/SteamDeck-KVM/releases/latest/download/SteamDeck-KVM-Install.desktop)** и нажмите на него дважды — работает так же, но Firefox иногда сохраняет файл как `….desktop.download`; в этом случае сначала верните окончание `.desktop`.

### Компьютер (Windows)

1. Скачайте `SteamDeck-KVM-<версия>-windows-x64-setup.exe` из [последнего выпуска](https://github.com/IBakhitov-lin/SteamDeck-KVM/releases/latest).
2. Запустите его. Программа установится без прав администратора, создаст ярлыки и запустится. Windows может предупредить о программе без подписи — нажмите «Подробнее → Выполнить в любом случае». Если нет [Deskflow](https://github.com/deskflow/deskflow) (бесплатный открытый сервер клавиатуры и мыши), приложение предложит поставить его одной кнопкой.
3. Нажмите **Включить**. Deck найдёт компьютер сам — обе машины должны быть в одной сети Wi-Fi.

## Как пользоваться

- **Перейти** — доведите курсор до края экрана или `Alt+Tab` на окно **Steam Deck** на компьютере; обратно — `Alt+Tab` на Deck'е. `Ctrl+Alt+→` / `Ctrl+Alt+←` тоже работают.
- **Игры** — когда игра прячет курсор (камера от третьего лица, шутеры), мышь крутит камеру без упора в край экрана и не уходит на компьютер. Откройте меню Steam (`Shift+Tab`, кнопка Steam) — курсор снова свободен; `Alt+Tab` выводит из игры всегда.
- **После перезагрузки** — включите Deck, нажмите **Включить** на компьютере. Машины помнят друг друга по номеру устройства, а не по адресу.
- **Экран Deck'а погас или Deck уснул** — курсор остаётся на компьютере.
- **Языки** — на Deck'е те же раскладки, что на компьютере; переключение — `Alt+Shift`. В игровом режиме новые раскладки вступают после его перезапуска.

## Обновление

В обоих приложениях появляется кнопка **Обновить**, когда вышел новый выпуск; она запускает установщик этого выпуска. Знакомство и настройки сохраняются.

## Удаление

- **Steam Deck** — откройте «Общая клавиатура и мышь» из меню приложений → **Удалить**. Можно сохранить знакомство с компьютером.
- **Компьютер** — Параметры Windows → Приложения → Установленные приложения → **SteamDeck-KVM** → Удалить. Можно сохранить знакомство со Steam Deck.

## Если не работает

- **Deck не находит компьютер** — мешают гостевой Wi-Fi с изоляцией устройств, разные подсети и VPN на компьютере. Впишите на Deck'е `server=192.168.x.x` в `~/.local/state/steamdeck-kvm/settings.conf`.
- **Ярлык на Deck'е ничего не делает** — это Firefox сохранил файл с окончанием `.desktop.download` (см. шаг 2 выше); воспользуйтесь командой терминала — она это не задевает.
- **Курсор дёргается или отстаёт** — установщик выключает экономию питания Wi-Fi для текущей сети; в другой сети запустите его ещё раз или снимите Steam → Настройки → Для разработчиков → **Включить управление питанием Wi-Fi**.
- **Всё ещё не работает** — в обоих окнах есть кнопка **Журнал**; журнал Deck'а ещё и в `journalctl --user -u steamdeck-kvm`.

## Как это устроено

На компьютере работает сервер Deskflow (протокол Barrier/Synergy). Клиент на Deck'е говорит на этом протоколе и отдаёт ввод прямо ядру Linux через `/dev/uinput` — Steam и игры видят обычные USB-клавиатуру и мышь. В игровом режиме курсор ведётся смещениями, на рабочем столе — абсолютной осью. Код: `apps/pc`, `apps/deck`, `core`, `tests`.

Общего буфера обмена и перетаскивания файлов нет: им нужна графическая оболочка, а работа мимо неё и даёт игровой режим. Связь не шифруется — только для доверенной домашней сети.
