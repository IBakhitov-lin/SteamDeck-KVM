# Steam Deck

**Назначение:** всё, что ставится на Steam Deck поверх ядра: служба, окно, установщик, удалятор
**Дата создания:** 2026-09-13
**Ответственный контур:** apps

## Содержимое

1. **`steamdeck_kvm_service.py`** — точка входа службы пользователя; `--status` и `--menu` для терминала
2. **`steamdeck-kvm-app.qml`** — окно состояния на движке окон рабочего стола
3. **`steamdeck-kvm-app.sh`** — запуск окна: qml6, qmlscene, иначе текстовое меню
4. **`steamdeck-kvm.service`** — шаблон службы пользователя systemd
5. **`install.sh`** — установка без пароля в обычном случае и переезд с прежней установки; скачанный отдельно, сам берёт архив последнего выпуска и сверяет его с `SHA256SUMS.txt`
6. **`uninstall.sh`** — удаление с выбором, сохранить ли знакомство с компьютером
7. **`SteamDeck-KVM-Install.desktop`** — ярлык «Установить», отдельный файл выпуска: скачивает `install.sh` по постоянной ссылке и запускает
8. **`steamdeck-kvm.png`** — значок — собирается, в историю не попадает

## Правила работы

- Файлы Linux хранятся с переводом строки Linux (`.gitattributes`)
- Окно ничего не решает само: всё идёт через локальный интерфейс службы `core/control_api_facade.py`
- Состояние Deck'а — в `~/.local/state/steamdeck-kvm`, программа — в `~/.local/share/steamdeck-kvm`
