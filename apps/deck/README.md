# apps/deck

Everything installed on the Steam Deck on top of `core/`.

- `steamdeck_kvm_service.py` — the user service; `--status` and `--menu` work from a terminal.
- `steamdeck-kvm-app.qml` — the status window.
- `steamdeck-kvm-app.sh` — starts the window with `qml6` or `qmlscene`, falls back to a text menu.
- `steamdeck-kvm.service` — systemd user unit template.
- `install.sh` — installer. Started by the install shortcut from the app packed inside it; started by the Update button with `--latest`, it downloads the latest release's install shortcut from github.com and continues from the app inside.
- `uninstall.sh` — uninstaller; asks whether to keep the pairing with the PC.
- `SteamDeck-KVM-Install.desktop` — template of the "Install" shortcut. The release build appends the app to it as `#P` comment lines, so the published shortcut installs offline.
- `steamdeck-kvm.png` — icon, generated by the release build and kept in the repository.

Where things live on the Deck:

- Program — `~/.local/share/steamdeck-kvm`
- Pairing and settings — `~/.local/state/steamdeck-kvm`; updates never touch it
- Linux files keep LF line endings (`.gitattributes`)
