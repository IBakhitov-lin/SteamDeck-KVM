# Копии общих модулей

**Назначение:** копии общих модулей оболочки для машины без канона автора; собираются сборщиком выпуска
**Дата создания:** 2026-09-13
**Ответственный контур:** apps

## Содержимое

1. **`tray-common.ps1`** — единственный экземпляр, цвет из палитры, значок символом
2. **`tray-place.ps1`** — место и раскладка плашки значка в трее

## Правила работы

- Руками не правится: сборщик выпуска перезаписывает копии из исходников при каждой сборке
- Приложение сначала ищет исходник в `C:\AI\scripts`, и только потом берёт копию отсюда
