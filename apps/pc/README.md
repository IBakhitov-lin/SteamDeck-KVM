# apps/pc

The Windows app: one "Enable" button, connection status, pairing, updates.

- `SteamDeck-KVM.vbs` — launcher without a console window; the shortcut points here.
- `SteamDeck-KVM.ps1` — behaviour: Deskflow server, pairing beacon, sleeping-Deck protection, updates.
- `app-window.ps1` — the window: palette, font, layout, dialogs, icon.
- `app-update.ps1` — update decisions without network or UI: pick the release and verify the downloaded installer against the checksum GitHub publishes.
- `lib/` — tray helpers bundled with the app.
- `SteamDeck-KVM.ico` — icon, generated by the release build.

Rules:

- User data lives in `%LOCALAPPDATA%\SteamDeck-KVM`, never in the program folder: an update replaces the folder.
- `.ps1` files with non-ASCII text are saved with a UTF-8 BOM; `.vbs` stays ASCII.
- After changing the window, run `private_tools/scripts/check_window_layout_script.ps1`.
