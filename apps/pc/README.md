# Приложение Windows

**Назначение:** окно «Общая клавиатура и мышь»: одна кнопка «Включить», состояние связи, знакомство с Deck'ом, обновление
**Дата создания:** 2026-09-13
**Ответственный контур:** apps

## Содержимое

1. **`SteamDeck-KVM.vbs`** — запускатель без окна консоли; его нажимает ярлык
2. **`SteamDeck-KVM.ps1`** — поведение: сервер Deskflow, маячок знакомства, защита от уснувшего Deck'а, обновление
3. **`app-window.ps1`** — оболочка окна: палитра, гарнитура, радиусы, раскладка, свои диалоги, значок
4. **`app-update.ps1`** — решения обновления без окна и сети: выбор выпуска, сверка суммы, раскладка файлов
5. **`lib/`** — копии общих модулей для тех, у кого нет канона автора
6. **`SteamDeck-KVM.ico`** — значок — собирается, в историю не попадает

## Правила работы

- Данные приложения живут в `%LOCALAPPDATA%\SteamDeck-KVM`, а не здесь: обновление заменяет эту папку целиком
- `.ps1` с русским текстом хранится с меткой кодировки; `.vbs` — только латиницей
- Правка окна — прогон `private_tools/scripts/check_window_layout_script.ps1` до чистого вывода
